# 2025 上海中考数学逐题索引

- [原卷图片预览](https://sjds.net/603939.html)：第三方网站，文章内可看原卷图片；领取电子版需关注公众号。不是本站托管的 PDF。
- [逐题考点分析](https://zy.21cnjy.com/23473882)：题号与主要考点的初始依据。该页面个别分值描述有疑点，本项目未导入分值。
- [沪教版初中数学目录](https://guchenlong.github.io/shu_xue/2_chu_zhong/hu_jiao_ban_2020/index.html)：用于推定建议年级，并非官方逐题年级划分。跨年级综合题只标主要年级或“跨年级”。

网站导入第 1-25 题的题型、考点与建议年级，不转载整张试卷题面。`learning_stage` 保持 `UNKNOWN`，不能仅凭建议年级推断孩子是否已学。导入数据见 `scripts/import-shanghai-2025-math.mjs`；可在网站逐题编辑修正。
